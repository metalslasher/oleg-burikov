# oleg-burikov

Astro marketing website deployed on Vercel. The project is currently being prepared for a personal-brand rewrite, so the technical baseline is intentionally kept small and easy to navigate.

## Stack

- Astro 6 with the Vercel adapter
- Tailwind CSS 4
- TypeScript
- Google Tag Manager and analytics pixels
- Server-side lead forwarding through `/api/lead`
- Vercel hosting

## Local Setup

Required runtime: Node.js `>=22.12.0`.

```bash
npm install
npm run dev
```

The dev server runs at `http://localhost:4321`.

Build and preview:

```bash
npm run build
npm run preview
```

## Environment

Create a local `.env` file or configure the same variable in Vercel.

| Variable | Used by | Description |
| --- | --- | --- |
| `LEADS_WEBHOOK_URL` | `/api/lead` | Server-side Google Apps Script or webhook URL for lead forwarding. |

Do not commit `.env`.

## Content And Pages

- Main home content, header navigation, and footer navigation live in `src/content/home-uk.json`.
- Astro pages live in `src/pages/**`.
- Reusable UI components live in `src/components/**`.
- Lead form validation and client submission live in `src/scripts/formValidation.ts`.
- Lead API validation, rate limiting, and webhook forwarding live in `src/pages/api/lead.ts`.

## Forms And Leads

Browser forms submit JSON to `/api/lead`. The API validates required fields, applies rate limits, blocks honeypot submissions, and forwards accepted leads to `LEADS_WEBHOOK_URL` from the server. The webhook URL is not exposed in client-side code.

## Deployment

The project is linked to Vercel project `oleg-burikov`.

- Build command: `npm run build`
- Output: Astro/Vercel server output
- Production domain: `https://www.oleg-burikov.com/`
- Sitemap is generated by `@astrojs/sitemap`
