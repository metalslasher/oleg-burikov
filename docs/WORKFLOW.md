# Як ми працюємо (Олег + Claude)

## Цикл одного раунду

1. **Збір правок.** Олег кидає скріни й коментарі по одній сторінці. Claude нічого не міняє, тільки записує в
   `docs/BACKLOG.md` (новий розділ «Раунд N»).
2. **Розбір.** Claude відповідає одним повідомленням: з чим згоден, де заперечує і чому, що знайшов сам, які питання
   блокують роботу. Для текстів дає 2–3 варіанти й позначає свій дефолт.
3. **Рішення.** Олег відповідає коротко («4.5 — Б, решта дефолт»). Без відповіді береться дефолт.
4. **Реалізація.** Claude робить увесь раунд, перевіряє в браузері (десктоп + 375px), запускає `npm run quality`,
   сам комітить і пушить у `main` (Vercel деплоїть сам) — без окремого питання.
5. **Огляд.** Олег дивиться на живому сайті; правки, якщо є, йдуть у наступний раунд.

Порядок раундів і загальний план — у `docs/BACKLOG.md` → «Дорожня карта». SEO робимо в кінці, коли тексти затверджені.

## Як давати правки, щоб було швидко
- Одне повідомлення = одна секція або тема. Скрін + що не так (+ як хочеться, якщо є бачення).
- «Можеш переписати» — нормально: Claude дасть варіанти.
- Якщо правка стосується фактів (роки, цифри, компанії) — це правда з LinkedIn / скрінів кабінетів, Claude не вигадує цифр.

## Яку модель / effort вибирати

| Тип задачі | Приклади | Модель · effort |
|---|---|---|
| Записати правки, дрібні тексти, видалити блок | раунди збору, заміна слів | Sonnet · low–medium |
| Раунд правок по сторінці | раунд 4 головної | Opus · medium |
| Логіка й форми, API, баги | маска телефону, валідація, трекінг-події | Opus · medium–high |
| Аудит, нова секція/сторінка, редизайн блоку, SEO-стратегія | SEO-прохід, нова сторінка послуги | Opus · high |
| Велика фіча або рефакторинг | англійська версія (i18n) | Opus · high/xhigh + plan mode |

Claude на початку кожного раунду пише рекомендацію; якщо поточна модель/effort завеликі чи замалі — скаже.

## Незмінні правила
- GTM / GA4 / Clarity / пікселі вантажаться стандартно — не чіпати без прямого запиту.
- Цифри в кейсах мають сходитися зі скрінами в `public/images/cases`.
- Мова сайту — українська, без зайвих англіцизмів; Олег не просить email у формі.
- Git (коміти, пуші) повністю на Claude — питати не потрібно.
